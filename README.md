# NFeJS

Historical Node.js work around NF-e XML, DANFE-related structures and Brazilian fiscal integrations. The source includes domain objects, XML utilities and a Firebird adapter.

## Historical maintenance status

This repository is retained as a legacy engineering reference, preserving its existing URLs and public history. The last source commit reviewed for this portfolio dates from 2019. Current dependencies, build compatibility, fiscal schemas and production operation have not been validated in this documentation review.

The presence of code for an earlier NF-e version is not evidence of current fiscal compliance. Review the implementation, licensing and operational requirements before reuse. No new production-support commitment is implied by this notice.
